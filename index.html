Pagamento pelo app

O contratante paga no app. O Toppa transfere direto para quem trabalhou.

Ninguém precisa combinar Pix por fora ou cobrar depois. O dinheiro passa pelo Toppa e cai na conta do freelancer quando o turno é confirmado.

1. Empresa paga pelo app

Ao reservar, escolhe pagar com depósito de 20% ou depois do evento.

2. O Toppa guarda o valor

O pagamento fica protegido até o trabalho acontecer.

3. Turno confirmado e avaliado

Depois de cada turno, os dois lados se avaliam no app.

4. Transferência direta

O valor vai do contratante para o freelancer. Quer receber em 24h? Taxa de 5%.

Dúvidas frequentes

Ficou alguma pergunta?

Quanto custa usar o Toppa?

Para freelancers o app é gratuito. Empresas pagam a partir de R$ 26,93 por mês no plano anual, ou R$ 35,90 no mensal. Nesta versão de teste nada é cobrado.

Preciso enviar documentos agora?

Não. Na versão de teste a verificação é simulada: você só clica para ver como funciona. No app final, a verificação usa documento oficial e selfie com prova de vida.

Como as notas são calculadas?

Ao final de cada trabalho, os dois lados se avaliam de 1 a 5 estrelas. A nota do perfil é a média das avaliações, como nos apps de mobilidade.

O que acontece quando os dois topam?

O chat é liberado para combinarem data, local, horário e valor do trabalho direto pelo app.

Posso cancelar a assinatura?

Sim. Os planos podem ser cancelados a qualquer momento.
